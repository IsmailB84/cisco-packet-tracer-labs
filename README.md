# Cisco Packet Tracer Networking Labs

## About This Repository
This repository documents my hands-on networking journey using Cisco Packet Tracer. These labs are designed to strengthen my understanding of networking fundamentals, routing, switching, network security, and infrastructure.

I'm building these projects as part of my development toward a career in Network Administration and Cloud Engineering.

## Technologies & Tools
- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 Addressing
- Ethernet Switching
- Network Troubleshooting

## Labs

| Lab | Project | Concepts |
|---|---|---|
| 01 | Small Business LAN | IPv4, switches, static addressing, ping, MAC tables |
| 02 | Connecting Two Networks | Routers, gateways, routing |
| 03 | DHCP Configuration | Dynamic IP addressing |
| 04 | VLAN Configuration | Network segmentation |
| 05 | Inter-VLAN Routing | Router-on-a-stick |
| 06 | Network Security | ACLs, port security |
| 07 | Multi-Router Network | Static routing |
| 08 | Troubleshooting Challenge | Network fault diagnosis |
| 09 | Enterprise Network | Integrated networking concepts |

## Repository Structure

Each lab includes a Packet Tracer simulation file and documentation explaining its purpose, configuration, and testing.

## Goals
- Develop practical networking skills
- Build a foundation for CCNA-level networking
- Practice troubleshooting real-world network scenarios
- Develop skills applicable to cloud infrastructure and network engineering
